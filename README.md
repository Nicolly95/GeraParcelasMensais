Esse codigo gera n parcelas de vencimentos (de boletos ou cartões) e pode ser armazenado em um banco de dados. 
Para esta classe eu utilizo as classes importadas Date para definir a data inicial da qual será baseana os calculos das proximas parcelas, 
juntamente com o SimpleDateFormat para setar o formato de datas aceito e o Calendar para manipular o intervalo entre datas.
Uso o laço for para iterar a contagem dos meses e adiciono uma unidade a mais nos meses do Calendar.
